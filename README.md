# SubUnicode

Unlimited subspaces in Unicode private use areas!

- This repository contains a Python implementation of SubUnicode.
- See [SubUnicode-Website](https://github.com/UTF-8000/SubUnicode-Website) for the full writeup.
- SubUnicode is in no way endorsed by or representative of the [Unicode Consortium](https://home.unicode.org/). This is a standalone project.

## Installing

Available on PyPI as [SubUnicode](https://pypi.org/project/SubUnicode/)

Recommended install using [pipx](https://github.com/pypa/pipx):

```
$ pipx install SubUnicode
```

provides

```
subunicode(1)
```
